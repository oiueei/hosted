# Contributing

**This repository is not where OIUEEI is developed.** It is the running
deployment behind [www.oiueei.com](https://www.oiueei.com) — the product from
[`oiueei/standalone`](https://github.com/oiueei/standalone) plus the thin
service layer one operator wraps around it (see [`README.md`](README.md)).

## Everything goes to the standalone repo

Bug reports, self-hosting problems, accessibility findings, translation
corrections, licence questions — all of it belongs in
**[`oiueei/standalone`](https://github.com/oiueei/standalone)** and its
`CONTRIBUTING.md`, which is the one kept current. This repo does not track it,
and an issue or pull request opened *here* will be closed with a pointer over
there.

## The short version of the standalone's rules

- **Pull requests are not being accepted yet.** One maintainer, and no
  contributor agreement in place — accepting outside code without one would
  permanently close the relicensing options that a single copyright holder
  keeps open. When that changes it is announced in the standalone's
  `CONTRIBUTING.md`. No timeline is promised.
- **Issues are welcome — in the standalone repo.** Bug reports, self-hosting
  problems, accessibility and translation findings all get read.
- **The licence is EUPL-1.2**, the same as the standalone: a strong copyleft
  that reaches use over a network. See [`LICENSE`](LICENSE).

Questions, or to discuss an idea before writing it: open an issue on
`oiueei/standalone`, or write to **maintainer@oiueei.com**.
